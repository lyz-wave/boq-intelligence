# 0003. 智能价格匹配采用“硬规格指数衰减核 + 多路混合检索”，并将纯深度学习模型封装为可插拔重排插件

系统线上默认的价格匹配流水线决定采用**“知识规则与硬约束路由 → 稀疏词权（BM25）+ 稠密语义向量 + 结构化属性多路召回 → 硬规格指数衰减核函数 + AHP 特征权重精细重排”**架构，而不直接以《公司重点科技项目申报书》中初步设想的“纯 LSTM 序列向量 + 余弦相似度”作为唯一线上匹配器。同时，将 `LSTM`、`TransE/R-GCN` 等神经网络与图谱模型封装为实现 `RerankerPort` 接口的可插拔重排插件。

在真实造价数据中（如 `data/二级泵站电缆综合单价.pdf`），第 9 项 `电力电缆 ZR-YJV-0.6/1KV-3*150+1*95`（综合单价 1194.67 元/m）与第 10 项 `电力电缆 ZR-YJV-0.6/1KV-3×25+1×16`（综合单价 133.15 元/m）的文本字面重合度极高，嵌入余弦相似度通常超过 0.96，但实际综合单价相差近 9 倍；同理，`土（石）方运输，运距5km` 与 `运距0.5km`、`地径≥0.3cm` 与 `地径≥1cm` 也存在同样的问题。纯文本向量模型对决定造价量级的核心规格数值缺乏硬区分度，必须在重排阶段引入针对硬约束规格槽位的数值衰减核函数：

$$K_{\text{spec}}(x_q, x_c) = \exp\left(-\alpha \cdot \frac{|x_q - x_c|}{\max(x_q, x_c)}\right)$$

## Considered Options

- **方案 A：仅使用 LSTM 提取文本向量并计算余弦相似度**
  - *放弃原因*：无法有效惩罚核心规格数值差异，极易导致“字面高度相似但单价相差数倍”的严重错配，无法满足一线造价编制与审价精度要求。
- **方案 B：完全抛弃深度学习与知识图谱，仅使用 SQL 精确匹配**
  - *放弃原因*：不同项目对同一工序的自然语言表述差异极大（如 `清表，推土机推土` vs `地表清理 0.05m厚`、`接地母线` vs `接地铜排`），纯精确查询召回率极低，且无法满足重点科技项目关于深度学习、知识图谱、论文与发明专利的考核要求。
- **方案 C：三段式混合检索 + 硬规格指数衰减核 + 可插拔深度学习/图谱重排插件（选定方案）**
  - *选定原因*：在工业生产上，通过混合召回保障高召回率，通过硬规格衰减核与 AHP 权重彻底消灭规格错配；在科研交付上，既融合了知识图谱推理与深度语义表征，又能在同一评测管线上通过插拔 `LstmCosineReranker`、`RgcnGraphReranker` 与 `HybridKernelReranker` 一键运行消融实验，直接支撑 SCI/核心论文、发明专利与《模型性能评估报告》。

## Consequences

- **生产级高精度与可解释性**：线上每一次价格推荐均能精确对齐硬规格槽位，并输出基于 AHP 权重与 SHAP 归因的特征贡献度及定额案例溯源。
- **内置科研评测基准台**：系统天然具备多算法对比评测能力，可直接输出各模型在 Top-1/Top-3 命中率、平均绝对百分比误差（MAPE）上的量化对比数据。
